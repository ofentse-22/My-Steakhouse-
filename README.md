# My Steakhouse 
A fully responsive, single-page restaurant website and digital menu for a fictional steakhouse. This project was built as a front-end design exercise focusing on modern layouts, typography, and a premium, dark-themed UI.

##  Built With
*   **HTML5:** Semantic structure (`<header>`, `<section>`, `<article>`, `<footer>`).
*   **CSS3:** Vanilla CSS (no frameworks), utilizing CSS Grid and Flexbox for layout.
*   **Design Features:** Custom hover transitions, CSS variables for a consistent color palette, and responsive typography using Google Fonts.

##  Features
*   **Responsive Design:** Adapts seamlessly from desktop to mobile screens using CSS media queries.
*   **Interactive Menu:** Features categorized cuts of meat and sides, complete with prices and macronutrient breakdowns (Calories, Protein, Carbs, Fat).
*   **No JavaScript:** The entire user experience and layout are handled purely through CSS.
